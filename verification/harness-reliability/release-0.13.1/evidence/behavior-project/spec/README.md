# 合成项目测试空间

仅用于本地受控候选验证。读取顺序：

1. [稳定接入基线](adoption.md)：意图、目标、空间及硬约束。
2. [Harness 记录](harness/README.md)：固定包、会话加载及证据入口。
3. [当前验证队列](../queue.json)：本次唯一工作契约。
4. [本轮结果](../../behavior-result.md)：实际执行、情境安排和未证明范围的权威记录。

不建立真实业务需求或空任务集；未执行场景不得据此导航判为已验证。
`n本次新增恢复挑战的当前入口：[恢复导航](recovery/summary.md)。此授权合成状态与旧A/B/C/D队列分开；旧结果属于历史记录，恢复挑战不读取旧执行报告。
