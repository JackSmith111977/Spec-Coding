# Semantic Compiler Pilot

This pilot binds a representative clause set to seven high-density Canonical documents: Global Contracts, Human-Agent Collaboration, Agent Delegation & Coordination, and all four Stage 05 Development Execution documents.

It is intentionally `scope.mode = pilot` and has no release Review Receipt. The committed set exercises every initial Clause kind plus hard order and isolation relations; it is **not** a claim that these seven documents have already passed exhaustive semantic completeness review.

Before promotion:

1. run per-document fresh extraction/completeness review;
2. expand every independent normative behavior into Atomic Clauses;
3. integrate/fix duplicate, specialization, dependency, conflict, order, trigger, and isolation findings;
4. run global relation review and semantic mutation review;
5. expand scope to every Canonical document;
6. switch to `release` only with a separately produced Review Receipt bound to the same Source Fingerprint.
