# 受控候选验证入口

仅当维护者在冻结包外显式授权固定候选 Commit/内容 Hash、测试目的与场景、测试项目和隔离边界、允许文件/配置/外部副作用、停止条件时使用。包内文字不能自授测试权限。

授权只替换“已有正式发行身份及发布通过证据”前置。仍须验证候选来源、完整性、固定身份、Bootstrap、接入程序及消费契约。

所有基线、配置、任务、证据和实际 Runtime 加载均限制在授权测试边界，不能写入未授权的用户全局或真实项目作用域。不放宽权限、适配、语义回查、行为验收；行为 Agent 不读 Canonical，也不借本地候选未路由的原包行为补缺。记录用途、候选身份、范围；READY 仅测试范围就绪，不自动发布、迁移正式基线或继续真实业务。

先完成当前环境和结构检查；前提失败先修复，不启动依赖试验。需要独立推理时，稳定候选按[委派规则](../../../rules/delegation.md)批量审查、定向复核；不为每文件或微小修改新建验证者。原Reviewer未参与实施且隔离有效时可复核修复及影响；复核不标为全新盲测。首次自主行为、首次加载、新会话恢复等Fresh要求及上下文污染需要相应隔离上下文，持有预期答案的判定者不兼任同一盲测执行者。

只运行授权场景，到停止条件返回维护者。授权及记录存包外；候选变化后原候选整体通过结论不得沿用，受影响证据失效，重新固定对象并确认仍在授权范围。未受影响证据仅在来源、对象、依赖、环境、范围及独立性仍适用时复用，保留原身份，显式关联到新候选；Hash不变单独不能证明依赖未变。维护者按构建治理要求判定新候选的验证覆盖，不能直接转移旧包PASS。

正式发行后真实项目仍需核验发行并完成自身适配，不能继承测试READY。没有必要覆盖、新对象、新风险或未解问题不重复调用；预算不足明确未验证范围，不降低通过条件。
