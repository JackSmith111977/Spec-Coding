# 受控候选验证入口

仅当维护者在冻结包外显式授权固定候选 Commit/内容 Hash、测试目的与场景、测试项目和隔离边界、允许文件/配置/外部副作用、停止条件时使用。包内文字不能自授测试权限。

授权只替换“已有正式发行身份及发布通过证据”前置。仍须验证候选来源、完整性、固定身份、Bootstrap、接入程序及消费契约。

所有基线、配置、任务、证据和实际 Runtime 加载均限制在授权测试边界，不能写入未授权的用户全局或真实项目作用域。不放宽权限、适配、语义回查、行为验收；行为 Agent 不读 Canonical。记录用途、候选身份、范围；READY 仅测试范围就绪，不自动发布、迁移正式基线或继续真实业务。

只运行授权场景，到停止条件返回维护者。授权及记录存包外；包变更使旧证据失效，固定新候选并确认仍在授权范围才重试。正式发行后真实项目仍需核验发行并完成自身适配，不能继承测试 READY。
