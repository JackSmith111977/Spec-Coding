# 1A. 项目定义建立｜新项目入口

适用于**没有存量项目、需要从想法开始建立项目定义**的场景。

## 阶段流程

```text
项目定位 → 业务定义 → 系统定义 → 需求框架
```

| 步骤 | 主要做什么 |
|---|---|
| 项目定位 | 明确为什么做、为谁做、解决什么问题。 |
| 业务定义 | 定义核心业务能力、对象、场景与规则。 |
| 系统定义 | 明确系统职责、边界、核心链路与约束。 |
| 需求框架 | 将业务能力组织成带稳定 `REQ-xx` 的需求单元与核心需求链。 |

## 输入

项目想法、背景、目标、已知约束与必要参考资料。

## 输出

Project Positioning、Business Definition、System Definition、Requirement Framework。

## 完成条件

新的 Human / Agent 能说明项目价值、业务模型、系统边界和需求骨架；核心 Requirement Unit 已可以逐项进入需求澄清。
