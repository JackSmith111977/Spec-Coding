# 1B. 项目认知建立｜存量项目入口

适用于**已有代码、系统或业务现状，需要先建立可靠上下文**的场景。

## 阶段流程

```text
项目导览 → 业务理解 → 系统理解 → 需求定位
```

| 步骤 | 主要做什么 |
|---|---|
| 项目导览 | 快速建立项目结构、入口和关键资料地图。 |
| 业务理解 | 理解核心业务对象、场景、流程与规则。 |
| 系统理解 | 理解系统模块、链路、数据、依赖与边界。 |
| 需求定位 | 将本次需求放回现有业务 / 系统中，定位变化点、影响面与 Gap。 |

## 输入

存量代码、文档、运行环境、已有业务资料与当前需求材料。

## 输出

Project Overview、Business Context、System Context、Requirement Context。

## 完成条件

新的 Human / Agent 能说明当前业务与系统如何工作，并明确本次需求“要变什么、变在哪里、哪里对不上”。
